# 多多商品素材下载器 · 操作说明

本文档面向日常使用，说明如何安装、登录、扫描与下载拼多多商品页素材。开发相关说明见 [README.md](./README.md)。

---

## 1. 插件能做什么

在拼多多 **商品详情页**（含 `goods_id` 的页面）自动识别并分类下载：

| 分类 | 说明 |
|------|------|
| 商品主图 | 轮播区原图 |
| SKU 图 | 规格 / 颜色等 SKU 图片 |
| 详情页图片 | 商品详情长图 |
| 详情页视频 | 商品官方介绍视频 |
| 卖家秀视频 | 评价区带视频的晒单 |

**原则**：尽量使用原图、原视频地址，去掉缩放与水印类参数，**不在插件内二次压缩**。

**适用浏览器**：Chrome、Microsoft Edge（及其他支持 Manifest V3 的 Chromium 内核浏览器）。

**适用网站**：`yangkeduo.com`、`pinduoduo.com` 上的商品页。

## 2. 安装与首次使用

### 2.1 安装扩展

1. 地址栏输入 **`chrome://extensions`**（Edge 为 **`edge://extensions`**）并回车。  
2. 打开右上角 **开发者模式**。  
3. 点击 **加载已解压的扩展程序**。  
4. 选择 **多多商品素材下载器** 文件夹（内含 `manifest.json` 和 `icons` 子文件夹）。  
5. 安装成功后，工具栏会出现扩展图标。

### 2.2 打开商品页并刷新

1. 在浏览器中打开任意 **拼多多商品详情页**（从 App 分享链接或搜索进入均可）。  
2. 按 **F5** 或 **Ctrl+R** 刷新一次页面（确保插件脚本已注入）。  
3. 页面 **右下角** 会出现红色按钮 **「素材下载」**；点击后展开 **多多商品素材下载器** 面板。

> 若看不到按钮：确认扩展已启用 → 刷新商品页 → 确认当前 URL 是拼多多域名且为商品详情页。

### 2.3 更新插件代码后

修改过插件文件后，请到扩展管理页点击该扩展卡片上的 **重新加载（↻）**，再 **刷新商品页**。

## 3. 登录拼多多（重要）

完整素材（尤其 **卖家秀视频**）通常需要 **已登录** 状态。

**推荐步骤：**

1. 在面板或扩展弹窗中点击 **「打开拼多多首页（登录 / 入口）」**，或自行打开 [https://mobile.yangkeduo.com/](https://mobile.yangkeduo.com/)。  
2. 在同一浏览器里完成拼多多登录。  
3. 回到 **商品详情页**，**刷新页面**，再点 **「重新扫描本页」**。

**说明：**

- 登录信息保存在 **浏览器账号 / Cookie** 中，插件 **不保存密码**。  
- 同一 Chrome/Edge 用户配置下，新开标签或新窗口打开商品页 **共用登录**，一般无需重复登录。

面板顶部若出现黄色提示「未登录或未加载完整商品数据」，请按上述步骤处理。

## 4. 界面在哪里

### 4.1 商品页右下角面板（主要操作区）

- **「素材下载」**：收起时显示的红色入口按钮。  
- **面板标题**：多多商品素材下载器；下方一行显示 **商品标题 · 商品 ID**。  
- **提示条**：登录、数据未就绪、无卖家秀等说明（黄/蓝）。  
- **工具栏**：全选、跳过已下载。  
- **分类列表**：五类素材，每类可展开/收起、按分类勾选。  
- **底部**：下载进度条、**下载已选**、**停止下载**、状态文字。

### 4.2 浏览器工具栏弹窗

点击扩展图标打开，用于：

- 查看当前标签是否为商品页，以及各类素材 **数量摘要**；  
- **打开拼多多首页（登录）**；  
- **重新扫描当前商品页**；  
- **打开页面右下角面板**；  
- **打开扩展管理页**（便于重新加载插件）。

当前标签不是拼多多或不是商品详情页时，部分按钮会不可用。

## 5. 标准操作流程（推荐）

```
安装扩展 → 打开商品详情页并刷新 → （如需）登录拼多多 → 重新扫描
    → 勾选要下的分类/条目 → 下载已选 → 在下载文件夹中查看
```

**逐步说明：**

1. **重新扫描本页**  
   - 进入商品页、滚动过详情或评价区后，点击 **「重新扫描本页」**。  
   - 扫描完成后，各分类括号内会显示数量，例如「商品主图（5/5）」。

2. **勾选素材**  
   - 使用 **全选** 可一次选中当前识别到的全部条目。  
   - 或分别勾选每个分类左侧的复选框，选中/取消该分类全部条目。  
   - 主图、SKU、详情图/视频：展开分类后可对单个缩略图勾选（数量特别多时可能只显示摘要，仍可通过分类复选框全选）。

3. **下载已选**  
   - 点击 **下载已选**，底部显示进度（如「下载中 3/10」）。  
   - 需要中断时点 **停止下载**；已完成的文件会保留。

4. **查看文件**  
   - 打开系统 **默认下载文件夹**，按下一节路径查找。

## 6. 下载保存位置与文件夹结构

根目录在浏览器的 **默认下载位置** 下：

```text
多多商品素材 /
  └── 商品ID_商品标题（截断）/
        ├── 01-商品主图 /
        │     └── 01.jpg、02_规格名.jpg …
        ├── 02-SKU图 /
        ├── 03-详情页图片 /
        ├── 04-详情页视频 /
        └── 05-卖家秀视频 /
```

- 文件名按分类内顺序编号（01、02…），部分带规格或标签后缀。  
- 若同名文件已存在，浏览器会自动 **重命名避免覆盖**（uniquify）。  
- 修改浏览器「下载位置」后，新文件会保存到新位置。

## 7. 常用功能说明

### 7.1 跳过已下载

- 默认开启 **跳过已下载**。  
- 插件会记录 **本商品 ID** 下已成功下载过的 **同一资源地址**，再次下载时会跳过，避免重复。  
- 若需对同一商品 **重新下载全部**，可点 **「清除本商品下载记录」**（仅清当前商品记录，不删硬盘上的文件）。  
- 取消勾选「跳过已下载」后，可再次下载已记录过的条目（可能产生重复文件）。

### 7.2 卖家秀视频（批量勾选）

卖家秀数量可能很多，面板提供 **分组勾选**：

- **每组数量**：默认 20，可改为 1～100，列表按组显示「第 1 组 · 第 1–20 个」等。  
- **按组勾选**：勾选某一组，即选中该组内全部卖家秀视频。  
- **只勾选前 N 个**：按当前「每组数量」或限制逻辑快速选中前若干条。  
- **清空卖家秀勾选**：仅取消卖家秀分类的勾选，其它分类不变。  
- **限制本次最多下载**：勾选并填写数量后，即使选中很多，**本次任务** 也只会下载前 N 个（按选中顺序）。

获取卖家秀前建议：已登录 → 在评价区切换到 **带视频晒单** → **向下滚动** 加载更多 → **重新扫描**。

### 7.3 展开 / 收起分类

每类右侧 **展开 / 收起** 只影响列表展示，不影响已勾选状态。

### 7.4 下载速度与失败重试

- 多个文件之间约有 **0.5 秒** 间隔，减轻浏览器与 CDN 压力。  
- 单个文件会先尝试 **直链下载**；失败时会尝试 **备用方式** 拉取后再保存。  
- 若显示部分失败，可仅勾选失败项 **再次下载已选**。

## 8. 常见问题

| 现象 | 建议处理 |
|------|----------|
| 没有「素材下载」按钮 | 扩展是否启用；是否拼多多商品详情页；**刷新页面**；扩展管理页 **重新加载** 插件后再刷新 |
| 弹窗提示「插件未连上此页」 | 同上，必须刷新商品页 |
| 各类数量为 0 | 等待页面加载完成；滚动详情/评价；点 **重新扫描** |
| 素材不全、无卖家秀 | **登录** 拼多多；评价区加载视频晒单后 **重新扫描** |
| 扫描后仍提示未登录 | 打开移动站首页确认能见到账号已登录；关闭无痕模式（无痕需单独登录） |
| 下载失败或很慢 | 检查网络；减少同时勾选数量；稍后重试；卖家秀可先 **限制本次最多下载** 试少量 |
| 找不到文件 | 浏览器设置里查看 **下载位置**；找文件夹 **多多商品素材** |
| 更新了插件代码 | 扩展管理 **重新加载** + 商品页 **F5** |

## 9. 使用注意

1. **权限**：插件需要访问拼多多相关站点及图片/视频 CDN，并在本机 **写入下载目录**；仅在您点击下载时发起下载。  
2. **合规**：请仅下载您有权使用的素材，遵守平台规则与著作权要求；本工具仅供学习与自用整理，不对具体使用场景做背书。  
3. **页面改版**：拼多多前端或接口变更可能导致某类素材暂时识别不到，可等待插件更新或反馈问题。  
4. **无痕 / 多配置文件**：每个浏览器配置文件登录与下载记录 **相互独立**。
