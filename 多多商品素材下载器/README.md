# 多多商品素材下载器

Chrome / Edge 扩展（Manifest V3）：在拼多多商品详情页分类下载主图、SKU 图、详情图/视频和卖家秀视频。优先原图原视频地址，去除缩放与水印参数，不做二次压缩。

**日常使用请阅读：[操作说明.md](./操作说明.md)**（安装、登录、扫描、下载、卖家秀分批、常见问题）。

## 安装

1. 打开 `chrome://extensions`（Edge：`edge://extensions`）
2. 开启 **开发者模式**
3. **加载已解压的扩展程序**，选择本文件夹（含 `manifest.json` 与 `icons/`）
4. 打开拼多多商品详情页，按 **F5** 刷新一次

## 文件说明

| 文件 | 作用 |
|------|------|
| `injected.js` | 页面内扫描商品 JSON / 接口中的媒体 URL |
| `content.js` | 注入右下角面板 UI |
| `background.js` | 批量下载、进度、取消、已下载记录 |
| `popup.*` | 扩展弹窗 |

本地测试产生的 `downloads/` 目录可忽略，不必提交到 Git。
